# Visual direction

Use the existing G513QY geometry and newer architectural studio. The subject is one real laptop with three measured power choices, so the model and data stay recognizable throughout.

Palette: studio graphite #161b21, soft white #f3f5f7, steel #aab4c2, Balanced blue #96baff, Eco mint #a8d5bf, with the model's actual cyan/violet keyboard lighting. Barlow carries the copy; Barlow Condensed gives measured values a compact shape. JetBrains Mono is reserved for the small runtime-state readout.

The hero begins as a product shot with short left-aligned copy in the empty left side of the studio. The model screen shows a measured-preset display. The middle expands into a comparison with common axes, then cuts to the already-built internal illustration. The end shows the actual Battery menu and an explicit next-login GPU note.

Layout plan:

    short hook     | laptop and its screen
    -------------------------------
    preset rows    | aligned power / throughput / temperature
    -------------------------------
    CPU / RX callouts on the existing cutaway
    -------------------------------
    actual Battery controls | project name and next-login note

Review: avoid a generic specification-card grid or a decorative neon motherboard. The existing physical model supplies the visual character. Charts encode measured quantities; small notes identify the experiment. The internal cutaway is labeled as an illustration. No private desktop or personal photograph is used as a film shot.

Motion reference: the revised Between windows film from the Install Hyprland and Caelestia session. Use 60 FPS, continuous fractional transforms and fifth-order easing with settled holds. The older rounded zoompan path is deliberately excluded.

The final shot now begins with an intact 1920×1080 desktop screenshot, captured while hovering the Battery icon on an isolated workspace. The camera holds the whole desktop, then moves the same surface to a 2.15× view of the lower-left mode menu. The final pose holds with copy on the right. There is no separate menu card or replacement crop.
